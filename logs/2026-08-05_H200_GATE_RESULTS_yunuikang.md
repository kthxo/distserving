### 계측기 오류의 내용 [측정, `managers/scheduler_runtime_checker_mixin.py:44-49`]
```python
num_used = self.max_total_num_tokens - (available_size + evictable_size)
```
`sglang:num_used_tokens`는 radix 상주분을 제외하고 **in-flight 보호 KV만** 센다. 따라서
- **P-b**: in-flight 상한 `4 × 32,376 = 129,504` → `0.80 × 262,246 = 209,797`은 **도달 불가능**.
  F1 실측 peak 128,705 = 상한의 **99.4%** → FAIL이 날 수밖에 없었다.
- **P-a**: `num_used ≤ N`은 위 식의 **산술적 항등식** → 캡이 무시돼도 실패할 수 없다(값이 음수로 갈 뿐).

사전 등록이 의도대로 작동했다 — 기준을 내리는 대신 **계측기 결함이 드러났다.**
F1b에서 peak in-flight는 **128,708** 로 F1의 128,705와 사실상 동일했고(0.002% 차),
축출량은 **두 run 모두 160,570** 으로 완전히 같았다 → probe는 결정론적이며 재현된다.
